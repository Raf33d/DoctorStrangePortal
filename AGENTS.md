# Project workflow

The user has authorized committing and pushing future edits in this project to
its configured GitHub remote after relevant checks pass. This authorization
continues unless the user changes it. Report the commit and push result.

If no destination is configured, ask for the GitHub repository URL. Do not guess
the destination, publish to a different repository, or force-push over remote work.

Keep `venv/`, caches, local credentials, and webcam captures out of commits.
`main.py` is the active magic-only application. Preserve its two-hand drawing,
hand-following circles, and fist-to-stop behavior unless requested otherwise.
